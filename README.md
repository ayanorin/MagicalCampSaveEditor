## What this is

A local, unofficial editor for Magical Camp v0.5 Fin (bugfix 8c) saves.
The editor does not upload your saves. It only runs in your browser.

The first page has three color schemes. Night is the default: dark, and easier to look at for a while. Eric is the blue menu from early in the game. Erica is the pink menu from the end. The choice is remembered in this browser, and Colors in the top bar changes it later.

## Open the editor

[https://ayanorin.github.io/MagicalCampSaveEditor/](https://ayanorin.github.io/MagicalCampSaveEditor/)

Open that link in Chrome or Edge. Your saves stay on your computer.

1. Close the game first (otherwise it can overwrite your edit, or your edit can overwrite its autosave).
2. Tick the warning checkbox ("I understand...").
3. Click "Open my game folder" and pick the folder that contains `Game.exe` and `Save01.rvdata2`.
4. Choose a save slot.

## Download and run it on your computer

If you want a copy that does not use the website, download the zip from the [latest release](https://github.com/ayanorin/MagicalCampSaveEditor/releases/latest).

Unzip it and open `index.html` in Chrome or Edge. After that it does not need the internet. Your saves are not uploaded.

Firefox and Safari cannot write into the game folder. There you open a single `.rvdata2` file, and the edited save (plus a backup of the original) goes to Downloads. Copy it over the original yourself.

## What you can edit

Easy mode:

- Overview: names and Eric(a)'s current title
- Relationships: affection for Natalie, Isabelle, Veronica, Alice, Wendy, Catherine, Marianne, Belle
- Eric(a): Acceptance, GirlScore, body values, and the spells the story teaches Erica (including Gust and Hurricane)
- Give items: searchable catalog of items, key items, weapons and armor
- Inventory & gold: everything you already own, plus gold
- Quick toggles: grouped on/off flags for missed scenes, shops, dungeons and lockouts (Enmaided!, Tilia timer, Giselle, and so on)
- Hidden content: hidden difficulties (including Hard, Lunatic and Nope), unreleased gear, and the title-screen Gallery

Manual mode: every named variable and switch, with the game's own labels and notes about what events use them.

## Give items

Use Give items to add things you do not already have. Search by name (for example "Cursed Wig"), set a quantity, press "Add to save". Nothing is written until you press Save changes.

Key items (quest objects) give you the object, not the story that normally comes with it. Example: the Cursed Wig opens the maid door, but Giselle's quest also needs the Enmaided! switch (Quick toggles).

## Hidden content

Difficulty (variable 301) and the unreleased items, weapons and Varek's Core are queued into the save you have open, like everything else. Hard, Lunatic and Nope are hidden by the World Improver menu; battles still apply them. Nope is effectively unwinnable. The TF Value Manipulator plays Lilith's transformation scene when you use it in the game.

The Gallery was never finished. It does not actually work, and there is very little in it. "Write gallery file" updates `SavingDataLocal.rvdata2` in the game folder (with a backup in `SaveEditorBackups`), which is what shows the title-screen button. Choosing Gallery starts a new game in that room. That needs "Open my game folder".

## Backups (on by default)

Before every write the original is copied to:

`<your game folder>\SaveEditorBackups\Save19_2026-10-08_22-33-00.rvdata2`

The game ignores that folder, so backups never show up as save slots. Restore any copy from the Backups page in the editor. Unticking the backup checkbox asks you to confirm first.

Please still keep your own copies of important saves.

## Safety

You edit at your own discretion. Wrong values can skip or lock scenes, or make a save unloadable. This tool is unofficial and only meant for this discontinued build of the game. Many of the options have not actually been tested.

The editor queues changes until you press Save. It then edits only the bytes it needs, re-parses the result, and refuses to write if anything unexpected differs. After writing, it reads the file back; if that check fails it restores the original automatically.

## Not included

The game's art, audio and full script are not bundled. `data/gamedata.js` contains names, descriptions and IDs generated from `Game.rgss3a` so the page works without loading the archive.
